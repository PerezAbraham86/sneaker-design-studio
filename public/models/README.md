# Phase 1N — Production 3D model asset

Place the owned or properly licensed production sneaker model here as:

`classic-low-top.glb`

The app manifest intentionally uses a standard GLB path so the asset remains portable between hosts.

Required addressable mesh names:
- upper_toe_box
- upper_toe_guard
- upper_quarter
- upper_eyestay
- upper_heel
- upper_collar
- upper_tongue
- sole_midsole
- sole_outsole

Do not commit a third-party sneaker model unless its license permits redistribution in this repository.

The current procedural WebGL sneaker remains the fallback until the production GLB is supplied and validated.
